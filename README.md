## Engineering Projects

### 1. Automatic Toe-In Alignment System
**B.Sc. Mechatronics Engineering Final Project | University of Iceland**

Designed, built and experimentally evaluated an ESP32-based automatic wheel-alignment prototype for a four-wheel-steering system.

The project combines infrared sensors, servo motor control, automated alignment algorithms and experimental validation.

- Conducted 30 experimental tests.
- Achieved mean absolute alignment errors between 0.35° and 2.19° across four wheels.
- Evaluated sensor performance, measurement accuracy and mechanical limitations.

**[Published Thesis – University of Iceland, Skemman](https://skemman.is/handle/1946/51741)**

### 2. ESP32 Multi-Sensor Hub
**ESP32 | MicroPython | Instrumentation**

A multi-sensor instrumentation prototype integrating ultrasonic distance measurement, acceleration, tilt and environmental monitoring.

- Servo-controlled ultrasonic radar.
- ADXL345 accelerometer and AHT20 environmental sensor.
- Shared I²C communication and OLED visualization.
- Serial CSV data streaming and PC-based visualization.
- Hardware troubleshooting and diagnostic testing.

**[View GitHub Repository](https://github.com/Logiquell/esp32-sensor-hub)**

### 3. PIC-Based Fall Detector & Environmental Logger
**PIC16LF1559 | Embedded C | Data Logging**

A low-power embedded system designed to detect free-fall events and log environmental measurements.

- Interrupt-driven ADXL345 accelerometer integration.
- AHT20 temperature and humidity measurements.
- EEPROM data storage with checksummed records.
- Watchdog-based wake-up and memory-constrained firmware.
- Battery-powered operation and calibrated drop testing pending.

**[View GitHub Repository](https://github.com/Logiquell/Fallskynjari)**

### 4. ESP32-S3 Smartwatch Firmware
**ESP-IDF | C | LVGL | Power Management**

Custom firmware for a Waveshare ESP32-S3 AMOLED smartwatch.

- Wi-Fi/NTP synchronization and RTC timekeeping.
- Battery monitoring and low-battery shutdown.
- Display and CPU sleep management.
- Firmware diagnostics and crash tracking.
- Reduced measured standby battery drain from approximately 10–12% to approximately 3.3% per hour.

**[View GitHub Repository](https://github.com/Logiquell/ESP32-Watch)**
